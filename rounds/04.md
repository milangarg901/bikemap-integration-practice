# 4 · Choose a meeting point

Read the club's candidate meeting points from `data/landmarks.json`. Choose the landmark closest to **any recorded sample** on the selected ride. For this local area the club uses the following approximate squared distance score, where differences are in degrees:

```text
score = (0.88 × difference_in_longitude)² + (difference_in_latitude)²
```

Compare full precision scores. On equal scores select the first landmark in file order, then the earliest sample for that landmark. Number samples from zero. Use all samples, including those after the preview. Print one JSON object with fields `landmark` (its name) and `sample` (the index). Save `meeting.png` with the full route and a single marker at the selected landmark's actual coordinates.

Run `python ride.py 4 --ride data/short.geojson` and `python check.py 4`. Then open `05.md`.
