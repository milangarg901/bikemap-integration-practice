# 2 · Connect the editor to the map service

Before drawing a ride, verify that the editor can download a base map. Start `python map_service.py` in another terminal. Leave it running. Use Ctrl+C to stop it after the session.

Implement `python ride.py 2`. Read the static map contract in `API.md`, send the documented base-map request to the selected service address and save the successful response bytes to `base.png` in the selected output directory. Create that directory if needed. Open the image and show the editor the street grid and canal.

Use a timeout. If the service rejects the request, surface the status and error message and exit unsuccessfully. A failed response must never overwrite a valid image. Run `python check.py 2`, then open `03.md`.
